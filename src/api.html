ONE LINK / KNOWN CONTROLS

Version 1 names.

Parameters are allowlisted. Unknown values are ignored. The app name in vw_mod must match its route. GET values remain in browser history and may appear in server logs, so never put API keys, passwords, private keys, passphrases, birth details or uploaded-image data in a URL.

NameAllowed valuesMeaning
api_ver1GET contract version. Omit to use version 1.
api_actconfigure, drawconfigure fills controls. draw runs one fresh chance draw after opening the page; I Ching casts all six lines. The key laboratory accepts configure only.
vw_moddice, coins, cards, runes, yijing, entropyTarget app. Use the value belonging to the page, for example entropy for /apps/entropy/.
src_camauto, cam1–cam4, browserSource for the next action. auto selects a camera; browser requests browser randomness without a camera.
cnt_itmApp-specific whole numberDice, free coins and runes: results to draw. Entropy lab: secret length in bytes (16, 32, 64 or 128). Entropy experiment: requested byte count. Cards: optional one-row matrix width when used alone.
HAND SCALE / CARDS

Deck & spread.

NameAllowed valuesMeaning
deck_typspanish, american, marseilleSpanish deck, 52-card American deck without jokers, or 78-card Tarot de Marseille.
deck_cnt40, 48Spanish deck size only: 40 excludes 8 and 9; 48 includes them.
lay_modmatrix, crossMatrix uses row order. Cross fixes five places: 1 centre, 2 above, 3 below, 4 left, 5 right.
cnt_lin1–78Matrix row count. Pair with cnt_col.
cnt_col1–78Matrix column count. The product must fit the selected deck.

For a one-row matrix, cnt_itm can supply its width by itself. Cross layout always contains five cards and ignores matrix dimensions.

HAND SCALE / COINS

Toss or cast.

NameAllowed valuesMeaning
coin_modfree, ichingIndependent coin tosses, or the three-coin I Ching method. I Ching casts six lines from bottom to top; the sixth action completes the hexagram.

The coin shows the owner-provided portrait on heads and a Maltese cross on tails. The result comes from the shared experimental sampler and browser randomness; the image is only a face design.

EARTH / ENTROPY LAB

Key type & file labels.

NameAllowed valuesMeaning
key_typed25519, rsa3072, rsa4096SSH key algorithm. It is selected only; key creation still requires the Generate button.
out_fmtssh, pem, jwk, openssh, pkcs8, hex, base64, base64url, base32, uuidPublic or private key container, or random-value encoding. The app applies a value only when the matching format selector offers it.
fil_id1–32 ASCII letters, numbers, hyphens or underscoresOptional prefix for downloaded filenames, such as server-1. It changes the filename only, never the generated value.

SSH QR files contain the public key. Secret and TOTP QR files contain their labeled secret values. All generation requires a button. Never put a private key, passphrase or generated secret in the URL.
